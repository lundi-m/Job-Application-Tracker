# Job Application Tracker

A console-based Java application for managing job applications, built using layered architecture and JDBC to demonstrate clean code structure and basic CRUD operations.

## **Features**

- Add a new job application

- View all applications

- Update application status

- Delete an application

## **Technologies Used**

- Java

- JDBC

- MySQL 

- Console input using Scanner

## Project Structure

+ Model – Represents the job application data

+ DAO – Handles database operations

+ Service – Contains validation and business logic

+ Main – Handles user input and menu


### How to Run

- Create the database table

- Set your database credentials in the DAO class

- Run the Main class

This project shows basic CRUD operations using simple validation and clean code structure.
